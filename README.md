# Kerala Taxiwalla Website

A free static website designed for Kerala Taxiwalla, Pathamuttam, Kottayam.

## Files
- `index.html` - website structure/content
- `style.css` - responsive design
- `script.js` - WhatsApp booking functionality
- `images/hero.jpg` - initial hero artwork

## Publish on GitHub Pages
1. Create/sign in to GitHub.
2. Create a new repository named `kerala-taxiwalla`.
3. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
4. Open repository Settings → Pages.
5. Under "Build and deployment", select "Deploy from a branch".
6. Select `main` and `/ (root)`, then Save.
7. GitHub will provide the free `github.io` website address.

## Before launch
- Replace the hero image with the uncle's real vehicle/business photo if available.
- Confirm the phone/WhatsApp number.
- Replace or remove any vehicle type that is not actually available.
- Add real customer reviews only with permission.
- Add real tour prices only after confirming them.
- For a custom domain later, buy the domain separately and connect it in GitHub Pages.
